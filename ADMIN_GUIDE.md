# Admin guide
Create products in WooCommerce; SKU, price, stock, attributes and photos are editable without code. Import CSV from **Products → Import** with preview and mapping. Manage leads in **Заявки Ferreta**. Administrator owns finance/settings; content staff edit pages/photos; warehouse edits stock; sales staff process leads/orders.

## Home page

Edit **Pages → Головна** to update the home page with Gutenberg. Each editorial section is a standard Group, Columns, Heading, Paragraph or Button block: click text to edit it, use the block toolbar for links, and use the six-dot handle to reorder or remove a whole section. The category grid and the four featured products remain dynamic: change categories under **Products → Categories** and change the featured products under **Products**. The latest four published products are shown automatically.
